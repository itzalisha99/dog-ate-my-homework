One line, under 200 characters, in which a dog explains why the homework got eaten — after being caught.

**The line:** "It was homework, so I did the work. The work was eating it."

The dog redefines "work" as eating: it genuinely believes it completed its assignment. Zero guilt, punch on the last word.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
